# Paradise Nursery - Online Plant Shop

Paradise Nursery is a dynamic React and Redux Web Application that allows plant lovers to browse, select, and purchase various houseplants.

## Project Details
- **Project Name:** Paradise Nursery Shopping Application
- **Tech Stack:** React, Redux Toolkit, CSS3, Vite / Create React App

## Features
- Interactive Landing Page with background image and "Get Started" call-to-action
- Dynamic Product Listing with categorized houseplants
- Interactive Shopping Cart managed by Redux Toolkit
- Total cost calculation, dynamic quantity controls, and cart badge counter
